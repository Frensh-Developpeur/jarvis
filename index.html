CONNEXION APPLE SANTÉ

Apple ne laisse pas les web apps lire l'app Santé. L'app Raccourcis le peut : elle m'enverra vos pas et votre énergie active plusieurs fois par jour. Configuration unique, environ 5 minutes.

1 · VOTRE LIEN PERSONNEL

Gardez ce lien pour vous : il permet d'écrire dans votre Jarvis.

2 · CRÉER LE RACCOURCI

App Raccourcis → onglet Raccourcis → + en haut à droite. Touchez le nom en haut → Renommer → tapez exactement Jarvis.
Pour ajouter une action : barre Rechercher des actions en bas → tapez son nom → touchez-la. Elle s'ajoute à la suite.

A
Les pas
  1. Rechercher des échantillons de santé → touchez Type → Nombre de pas. Touchez Ajouter un filtre → Date de début → est aujourd'hui.
  2. Calculer des statistiques → touchez Moyenne → choisissez Somme.
  3. Définir la variable → touchez Nom de la variable → tapez Pas. (La valeur se met toute seule sur Statistiques.)
B
Les calories
  1. Rechercher des échantillons de santé → Type Énergie active → filtre Date de début est aujourd'hui.
  2. Calculer des statistiques → Somme.
  3. Définir la variable → nom Energie.
+
Facultatif : poids et métabolisme CALCUL ADAPTATIF

Pour un objectif calories encore plus précis (module Nutrition). Vous pouvez aussi saisir vos pesées à la main dans Jarvis.

  1. Rechercher des échantillons de santé → Type Poids → Trier par Date de début, Ordre Plus récent en premier → Limite activée : 1. Puis Définir la variable → Poids.
  2. Rechercher des échantillons de santé → Type Énergie au repos → filtre Date de début est hier. Puis Calculer des statistiques → Somme, et Définir la variable → Repos.
C
L'envoi à Jarvis — l'étape importante
  1. Ajoutez Obtenir le contenu de l'URL.
  2. Touchez le champ URL (texte bleu) → collez votre lien (étape 1).
  3. Touchez la petite flèche › à droite de l'action (ou Afficher plus) pour ouvrir les options.
  4. Méthode : touchez GET → choisissez POST.
  5. En-têtes : ne touchez à rien.
  6. Corps de la requête : choisissez JSON. Une ligne Ajouter un nouveau champ apparaît.
  7. Pour chaque ligne du tableau ci-dessous : touchez Ajouter un nouveau champ → choisissez Texte → dans Clé, tapez le nom exactement (en minuscules) → touchez Texte à droite → au-dessus du clavier, touchez Variables (ou l'icône ✦) et choisissez la variable indiquée.
    CléTypeValeur (variable)
    stepsTextePas
    energyTexteEnergie
    weightTextePoids (facultatif)
    basalTexteRepos (facultatif)

3 · TESTER

Touchez ▶ en bas du raccourci. La première fois, iOS demande l'accès à Santé : autorisez Nombre de pas et Énergie active. Le raccourci doit se terminer sans erreur. Revenez ici :

4 · AUTOMATISER

  1. Raccourcis → onglet Automatisation → + (ou Nouvelle automatisation).
  2. Choisissez Heure de la journée → réglez 7:00, Répéter : Quotidiennement.
  3. En bas, cochez Exécuter immédiatement (et désactivez M'avertir lors de l'exécution) → Suivant.
  4. Choisissez votre raccourci Jarvis.
  5. Refaites-le pour 10:00, 12:00, 14:00, 17:00, 19:00 et 21:00 : plus les synchronisations sont fréquentes, plus l'objectif calories suit fidèlement votre journée.

Le bouton « ↻ Synchroniser » du hub lance aussi le raccourci à la demande.
